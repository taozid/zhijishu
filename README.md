# 职场高情商沟通教练 / Workplace EQ Communication Coach

个性化职场沟通教练，越用越懂你。先建立你的沟通风格画像（四种方式：授权分析钉钉/飞书聊天记录、发聊天截图、选择题测评、直接对话），并持续沉淀同事画像与长期记忆；对象是老板/领导时自动启用「老板视角」方法论。每个场景生成 2-3 个可直接复制发送的话术版本，附策略说明与对方反应预判。

## 安装

本技能遵循通用 Agent Skills 约定（SKILL.md + 辅助文件），任何支持该约定的 agent 均可安装：

- **QwenWork**：打开 `.skill` 文件点「保存技能」；或把本目录拷入 `~/.qwenworkcn/skills/`
- **Claude Code**：把本目录拷入 `~/.claude/skills/`（用户级）或项目的 `.claude/skills/`
- **Cursor / Codex / OpenCode 等**：拷入对应 skills 目录（如 `.agents/skills/`），或在项目指令文件（AGENTS.md / rules）中引用 SKILL.md
- **git**：`git clone <本仓库>` 后按上述方式拷贝目录

## 使用

安装后直接在对话里描述场景即可：

- 「同事答应周三给方案但还没给，想催又不想得罪人」
- 「要跟老板汇报项目延期，先分析老板会怎么想，再给我话术」
- 「记住这个：X老师特别抠细节，下次同步要带数据截图」

首次使用会引导你选择建档方式（连接办公软件 / 发截图 / 测评 / 直接对话）。

## 数据与隐私

- 个人数据（profile.md 画像、people.md 同事画像、memory.md 长期记忆）**只存本机**，默认在 `~/.eq-comm-coach/`；QwenWork 环境复用 `~/.qwenworkcn/eq-comm-coach/`；可用环境变量 `EQ_COACH_DATA` 覆盖
- 仓库与 `.skill` 分享包**只含技能本体**，不含任何个人数据
- 说「清空全部数据」可一键删除本机教练数据（移入废纸篓，可恢复）；说「删掉关于X的记录」可定向删除
- 聊天记录分析需明确授权并预告范围；只分析用户本人发送的消息；画像只存风格级笔记，不存原始聊天内容
- 钉钉（dws）/飞书（lark-cli）分析为可选增强；环境无相应连接器时自动降级为截图/测评/直接对话，不影响核心功能
